# 사이 (SAI) — 내 이야기를 발견하는 사주 놀이터

맥미니에서 실행하는 사주 서비스입니다. 기본 실행 모드는 로컬 LLM이 모든 사주 해석을 작성하는 홈서버입니다.

```bash
npm ci
# .env가 없을 때만 .env.example을 복사하고 로컬 AI 설정을 입력하세요.
npm start
```

`http://127.0.0.1:3000`을 여세요. 월별 주제·상세보기·사주·궁합·대운·연운·택일은 로그인 없이 로컬 AI로 생성합니다. 오늘의 운세·일일 상담·프로필 저장은 카카오·네이버 로그인이 필요합니다. 만세력 계산은 기존 코드를 사용합니다. AI 오류 때는 재시도 안내를 표시하며 규칙 해석으로 대체하지 않습니다.

설치·설정·공개 도메인·실제 로그인 등록·자동 실행은 [홈서버 안내](docs/HOME_SERVER.md)를 참고하세요. 핵심 답변은 짧은 한 문장으로 실시간 표시하고, 상세보기는 선택한 항목만 생성합니다. 같은 세션의 완료된 결과는 하루 동안 재사용합니다.

## 기존 브라우저 체험판

기존 만세력 화면과 계산을 유지하면서, 사주아이를 참고한 기능을 **서버 없이 시험하는 브라우저 체험판**입니다. 현재 `npm start`는 실제 홈서버를 `http://127.0.0.1:3000`에 띄우고 모든 사주 해석을 로컬 LLM에 요청합니다. 아래 브라우저 체험판은 `npm run start:demo`로 실행합니다. 홈서버 설정은 [홈서버 안내](docs/HOME_SERVER.md)를 참고하세요.

## 시작하기

Node.js 22 이상에서 실행합니다.

```bash
npm ci
npm run start:demo
```

브라우저에서 `http://127.0.0.1:4173`을 여세요. 모든 화면과 체험 흐름은 서버 API나 AI 키 없이 동작합니다. 달력 계산 라이브러리도 저장소의 `vendor/lunar.js`를 사용하므로 첫 방문 때 CDN 연결이 필요하지 않습니다.

## 체험할 수 있는 기능

- 기존 만세력의 양력·음력·윤달·네 기둥·지장간·십성·대운 계산을 사용합니다. 해석 코드는 만세력 결과를 읽기만 하고 계산 결과를 변경하지 않습니다.
- 네 기둥, 월지, 지장간, 대운을 함께 읽는 새 해석 엔진이 강점, 주의할 패턴, 구체적인 생활 장면, 다음 행동을 같은 규칙으로 요약·상세 보고서·주제 카드에 전달합니다. 한계 설명을 근거와 반대 단서에 붙이며, 질병·수익·결혼 등 사건을 확정하거나 통계 확률인 것처럼 말하지 않습니다. 여기 쓰인 가중치는 사이의 명시적인 편집 기준이며, 검증된 명리학 학파의 신강·용신 판정 또는 미래 예측 성능을 주장하지 않습니다.
- 카카오·네이버·구글 테스트 로그인 및 한 테스트 계정에 연동, 출생 정보, 마이페이지, 무료 운세·상담 보관함, 990원 상품 결과 보관함.
- 로그인 후 매일 한 번 오늘의 운세, 한국 시간 하루 한 번 고민별 규칙 상담.
- 990원 사주·궁합·대운·연운·택일 결과 미리보기와 테스트 구매. 같은 상품·조건의 반복 구매는 하나의 항목으로 처리하며 구매 실패는 보관함에 추가하지 않습니다.
- X, 네이버 블로그 링크, 공유 가능한 앱 메뉴, 인스타그램용 이미지 저장·공유, 문장·링크 복사.
- 검색과 주제별 필터가 있는 자주 묻는 질문.
- 새로 만든 토끼 캐릭터 그림, 분야별 상품 일러스트, 성향 배지·오행 그림, 화면 전환 효과.

## 테스트와 운영의 차이

로그인 버튼은 실제 소셜 인증을 하지 않습니다. 모든 테스트 계정은 브라우저 저장소 안에만 존재합니다. 브라우저를 바꾸면 계정·상담·구매 내역을 공유하지 않습니다. 오늘의 사용 제한도 이 로컬 테스트 데이터에만 적용됩니다. 구매 금액은 화면에 990원으로 보이지만 실제 청구는 0원입니다. 공유 화면은 링크, 이미지, 문장을 준비하며 SNS에 직접 게시하지 않습니다.

`마이페이지 → 이 브라우저의 테스트 데이터 모두 삭제`에서 저장된 프로필·계정·무료 이용·구매 기록을 초기화할 수 있습니다. 이 체험판은 실제 로그인을 보호하거나 부정 사용을 막는 서버 보안 경계가 아닙니다. 공개 서비스 운영 전에 OAuth, 서버 저장, 인증·접근 권한, 결제사 검증, 실제 일일 한도, 개인정보 고지와 삭제 정책을 별도로 연동해야 합니다. 이를 위해 별도 데이터베이스나 인증 서비스를 자동 생성하거나 외부 계정·결제 정보를 요청하지 않습니다.

## 구성

- `pages.js`: 기존 만세력 입력·화면 표시와 주제 카드 연결
- `insight-engine.js`: 공통 원국 해석·요약·상세 보고서·궁합·대운·연운·택일·상담 규칙
- `demo-api.js`: 브라우저에 저장하는 테스트 로그인·계정·일일 사용·구매 기록
- `experience.js` / `experience.css`: 상품과 무료 서비스, 공유, FAQ, 캐릭터 표현
- `assets/`: 이 프로젝트를 위해 만든 토끼 캐릭터·궁합·달력 삽화
- `vendor/lunar.js`: 기존 만세력 계산에 사용하던 `lunar-javascript@1.7.7`와 동봉 라이선스
- `server.js`: 저장소에 있던 별도 Node·SQLite 실험 서버. `npm run start:legacy`로만 실행하며, 새 브라우저 테스트 계정·상품 흐름과 연결되지 않습니다.

## 검증

```bash
npm test
```

전체 Node 테스트가 통과했습니다. 해석 테스트는 같은 일주라도 나머지 원국 차이가 결과에 반영되는지, 요약과 상세가 같은 근거를 쓰는지, 결합·충돌 단서가 공존할 때 둘 다 보존하는지 확인합니다. 브라우저 저장 테스트는 소셜 테스트 연동, 한국 시간 날짜 경계, 일일 무료 상담, 중복 구매, 구매 실패, 저장소 오류를 확인합니다.

## 맥미니 실제 로그인·로컬 AI 서버

새 홈서버 모드에서는 카카오·네이버 OAuth 로그인, 서버 SQLite 저장, 계정 연동·삭제와 Ollama 상담을 사용합니다. 기존 체험판은 `npm run start:demo`로 유지하고 기본 `npm start`는 홈서버를 실행합니다.

`.env.example`을 `.env`로 복사해 설정한 뒤 `npm run start:home`을 실행하세요. 앱 키가 없으면 실제 소셜 로그인은 사용할 수 없습니다. 도메인 등록, HTTPS 터널, 공급자 앱 설정과 macOS 자동 실행 방법은 [홈서버 안내](docs/HOME_SERVER.md)를 참고하세요. 실제 공급자 로그인과 모델 성능은 별도 실기 검증이 필요합니다.
