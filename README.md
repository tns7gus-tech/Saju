# 사이 (SAI) — 사주로 시작하는 대화

자체 만세력 생성에 필요한 역법·규칙과 첨부 화면 검증 결과는 [만세력 엔진 조사 문서](docs/MANSE_ENGINE.md)에 정리했습니다.

만세력 캡처를 기반으로 자기 탐색 보고서를 만들고, 소개팅에서 바로 쓸 수 있는 대화 카드를 제공하는 모바일 웹 MVP입니다.

## 실행

Node.js 22.13 이상이 필요합니다. 외부 패키지는 설치하지 않습니다.

```bash
cp .env.example .env
# .env 값을 배포 환경 변수로 설정하거나 셸에서 export 하세요.
OPENAI_API_KEY=... npm start
```

`http://localhost:3000`에서 확인합니다. `.env` 파일은 자동으로 읽지 않으므로 로컬에서 환경 변수를 셸에 직접 설정하거나 `node --env-file=.env server.js`를 실행합니다. `OPENAI_API_KEY`가 없으면 **데모 모드**로 실행되어 이미지 분석을 하지 않고 안내 문구만 반환합니다. 실제 OpenAI 요청은 서버에서만 전송되며 키는 브라우저 코드에 들어가지 않습니다. `npm test`로 핵심 API 테스트를 실행합니다.

정적 GitHub Pages만으로는 로그인, 추천 보상, OpenAI 서버 요청을 실행할 수 없습니다. 이 저장소를 Node 서버를 실행할 수 있는 호스팅에 배포하고, 운영 환경에서 `OPENAI_API_KEY`, `NODE_ENV=production`, `PUBLIC_ORIGIN=https://실제도메인`, 영속적인 `DATA_DIR`을 설정해야 합니다. HTTPS와 백업이 필요합니다. 서버를 여러 인스턴스로 늘릴 때에는 SQLite 파일 공유 대신 운영 DB로 교체해야 합니다.

## 현재 동작

- 이미지 선택 또는 모바일 카메라 촬영. 4MB 이하 JPG/PNG/WEBP. 외부 무료 만세력 페이지에서 캡처를 만드는 링크도 제공합니다. 원본 이미지는 디스크에 저장하지 않습니다.
- AI가 이미지를 근거로 12개 주제의 보고서를 생성합니다. 보이지 않는 항목은 추정하지 않도록 지시합니다. 원국 계산을 검증하는 별도 역법 엔진은 **아직 없습니다**. 사진의 판독과 명리 해석이 맞는지는 사람이 검토해야 합니다.
- 게스트에게는 서버가 잘라낸 첫 300자만 전송합니다. 전체 본문은 CSS로만 숨기지 않고 서버 권한 확인 후에만 반환합니다.
- 가입한 사용자는 매주 수요일(기본값, `FREE_WEEKDAY=0..6`으로 변경 가능) 한국 시간에 전체 결과를 볼 수 있습니다. 무료 요일이 아닌 날에는 추천인 5명의 가입으로 받은 이용권 1장을 사용하면 사용 시점부터 24시간 동안 접근할 수 있습니다.
- 가입한 추천인 5명당 이용권 1장. 클릭이나 공유는 실적으로 집계하지 않습니다. 추천받은 사람은 대화 카드를 체험할 수 있습니다. **이메일 인증과 부정 가입 탐지는 아직 없어 운영 환경에서 보상 악용을 막으려면 인증 연동이 선행되어야 합니다.**
- 결과와 이메일은 로컬 SQLite에 저장됩니다. `/api/account/delete` API로 로그인 계정과 결과를 삭제할 수 있습니다. 개인정보 처리방침과 사용자 화면의 계정 삭제 버튼, 보고서 보존 기간 정책은 실제 서비스 오픈 전 추가해야 합니다.
- 실제 썸/결혼 성공담이 없으므로 예시 후기를 만들지 않았습니다. 사례 게시 전 당사자 동의와 사용 범위를 받아야 합니다.

## PMF 가설과 Dropbox 벤치마킹

Dropbox의 초기 가치: 파일을 어느 기기에서나 쉽게 동기화하고 공유하는 경험. 제품 작동 모습을 보여주는 데모와 친구에게 공유할수록 양쪽 모두 저장 공간이 늘어나는 추천 구조가 입소문을 도왔습니다. [Dropbox 공식 추천 설명](https://blog.dropbox.com/topics/company/dropbox-referrals-are-now-twice-as-nice), [현재 추천 안내](https://www.dropbox.com/refer).

이 서비스의 좁은 첫 고객은 **첫 만남에서 대화를 시작하기 어려운 소개팅 참가자**입니다. 첫 가설은 “사주 결과의 길이”보다 “실제로 사용한 질문 한 개”가 가치를 만든다는 것입니다. 가입 전에 카드 3개를 체험하고, 캡처 분석의 첫 부분을 읽고, 더 알고 싶을 때만 가입합니다. 초대받은 사람도 카드를 사용할 수 있어야 추천이 자연스럽습니다.

### 2주 검증

실제 소개팅·미팅 경험이 있는 20명에게 모바일 링크를 보내고 다음을 묻습니다.

1. 마지막으로 첫 대화가 끊긴 순간은 언제였나요? 그때 사주 카드가 있었다면 꺼냈을까요?
2. 카드 3개 중 실제로 누구에게 어떤 문장을 보냈나요? 상대는 어떤 반응이었나요?
3. 기존 사주 앱, 밸런스 게임, MBTI 질문보다 이 방식이 나았던 이유가 있었나요?
4. 다음 만남에도 다시 쓰겠나요? 친구 한 명에게 지금 링크를 보내겠나요? 전체 결과에 돈을 지불할 의사가 실제로 있나요?

측정: 카드 열람 → 실제 사용 → 재사용 → 자발 공유 → 추천 가입 → 전체 결과 열람. 이벤트는 `events` 테이블에 최소 항목만 저장합니다. 20명 중 **10명 이상 카드/결과 열람, 5명 이상 자발 공유, 3명 이상 재사용 의사**를 초기 기준으로 두고, 결제 의사는 별도 실제 결제 실험에서 확인합니다. 사용자가 대화를 시작하지 않거나 가입 전에 이탈한다면 유료 긴 보고서 확장보다 질문의 맥락과 품질을 먼저 고칩니다. 가설 기준이지 PMF를 이미 달성했다는 의미는 아닙니다.

## API와 주의점

`GET /api/bootstrap`, `POST /api/register`, `POST /api/login`, `POST /api/logout`, `POST /api/analysis`, `GET /api/analyses/:id`, `POST /api/redeem`, `POST /api/event`, `POST /api/account/delete`.

비밀번호는 scrypt로 해시하고 세션은 HttpOnly 쿠키로 전달합니다. 원본 이미지는 저장하지 않지만 OpenAI API로 전달되며 생성된 보고서에는 출생 정보가 포함될 수 있습니다. 사용자에게 데이터 사용과 삭제 방법을 고지해야 합니다. 공개 서비스에는 가입 이메일 인증, IP 기반 악용 방지, 접근 로그/모니터링, 개인정보 처리방침, 백업 및 삭제 UI가 추가로 필요합니다. 결제 기능은 구현되지 않았습니다.

## 원문 요구사항 반영

`prompts.js`는 제공된 긴 프롬프트의 12개 출력 순서와 근거 중심 해석, 어려운 용어의 쉬운 풀이, 돈·직업·연애·결혼·건강·가족의 균형, 대운·세운의 조건부 분석을 담은 웹용 요약 버전입니다. 이미지에 없는 정보를 채우거나 사건·질병·수익을 단정하지 않도록 제약했습니다. 모델의 출력 길이 제한 때문에 12개 항목 각각 3~6문단을 항상 보장하지는 않습니다. 장문 보고서는 단계별 생성과 내용 검수를 붙인 뒤 제공하는 편이 안전합니다.
