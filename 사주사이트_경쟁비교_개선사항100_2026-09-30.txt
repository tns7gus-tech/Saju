로그인 API는 있지만 공개 도메인과 카카오·네이버 앱 키는 아직 준비되지 않았습니다. 현재 유료 결제는 비활성화되어 있습니다.

001. [P0 / 대] 공개 도메인과 HTTPS 접속 완성
현재: 기본 서버 주소가 localhost이고 도메인이 없습니다.
보완: 도메인, HTTPS 프록시 또는 터널, PUBLIC_ORIGIN을 하나의 운영 주소로 연결합니다.
완료 기준: 집 밖의 휴대전화에서 입력·결과·로그인 복귀까지 같은 HTTPS 주소로 동작.

002. [P0 / 중] 카카오 로그인 실제 개통
현재: OAuth 서버 코드는 있으나 앱 키 등록 전입니다.
보완: 개발자 앱과 허용 도메인·콜백을 설정하고 로그인 취소·만료·재로그인까지 확인합니다.
완료 기준: 실제 카카오 계정으로 가입·로그아웃·재로그인 시 저장 정보가 정상 복구.

003. [P0 / 중] 네이버 로그인 실제 개통
현재: 네이버 OAuth 구현은 있으나 앱 등록 전입니다.
보완: 서비스 URL·콜백·필요한 동의 항목을 등록하고 공개 사용 조건을 확인합니다.
완료 기준: 개발자 본인 외 계정에서도 정상 로그인하고 오류 안내가 사용자 언어로 표시.

004. [P1 / 소] 첫 화면의 서비스 약속을 한 문장으로 확정
현재: ‘사주로 시작하는 사이’와 대화 소재라는 방향이 있습니다.
보완: 관계 중심 서비스인지 종합 상담 보고서인지 우선순위를 정하고 제목·설명·메뉴를 통일합니다.
완료 기준: 처음 보는 5명 중 4명이 서비스의 핵심 가치를 같은 방향으로 설명.

005. [P1 / 중] 입력 전 익명 샘플 보고서 제공
현재: 출생 정보를 넣기 전 실제 결과의 깊이를 판단하기 어렵습니다.
보완: 가상 인물의 짧은 미리보기와 상세 한 항목을 읽기 전용으로 보여줍니다.
완료 기준: 개인정보 입력 없이 결과 형태·근거·분량을 확인 가능. 실사용자 자료는 사용하지 않음.

006. [P0 / 소] 무료·준비 중·이용 제한을 메뉴에서 바로 안내
현재: 결제는 비활성화되었고 일부 기능은 로그인 또는 하루 제한이 있습니다.
보완: 메뉴와 실행 버튼에 무료 범위·로그인 필요·하루 횟수·결제 준비 중을 명확히 표시합니다.
완료 기준: 실행 후 처음 제한을 알게 되는 상황이 없고 실제 청구가 있는 듯한 표현 제거.

007. [P1 / 소] 두 번 방문한 사람을 위한 바로 보기
현재: 첫 입력 흐름이 화면 중심입니다.
보완: 동의하에 저장한 계정에는 ‘내 만세력’과 ‘오늘 이야기’를 첫 화면에서 바로 여는 동선을 제공합니다.
완료 기준: 기존 이용자는 날짜를 다시 입력하지 않고 두 번 이내의 조작으로 결과 접근.

008. [P1 / 중] 이용 목적별 시작 버튼
현재: 같은 입력 양식으로 여러 주제에 진입합니다.
보완: 금전·연애·직업 등 궁금한 주제를 먼저 고르면 결과 화면에서 그 주제를 우선 노출합니다.
완료 기준: 선택한 목적이 입력·결과·상세 보기까지 유지.

009. [P0 / 중] 테스트용 문구와 운영용 화면의 단일화
현재: home-server.js가 index.html의 테스트 문구를 문자열 치환합니다.
보완: 운영 상태를 명시적으로 렌더링하고 ‘서버 전송 없음’ 등 데모와 운영의 차이를 한곳에서 관리합니다.
완료 기준: 운영 서버의 설명·FAQ·버튼이 실제 인증·저장·청구 동작과 일치.

010. [P1 / 중] 첫 사용 안내를 세 동작으로 줄이기
현재: 사용법 설명은 있으나 실제 결과 조작을 함께 배우는 안내는 제한적입니다.
보완: 첫 결과에서 ‘표 보기→주제 보기→선택한 상세 보기’만 안내하고 다시 보기를 제공합니다.
완료 기준: 안내를 건너뛸 수 있고 재방문 때 반복 노출하지 않음.

완료 기준: 결과에서 양력·음력을 혼동하지 않고 오류 시 어느 입력을 고칠지 알 수 있음.
